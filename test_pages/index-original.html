Эффект №1 · Радиальный градиент

Поле ввода, обёрнутое в div с radial-gradient, который следует за курсором. Градиент просвечивает через отступ 2px, создавая эффект «светящейся обводки».

Эффект №2 · Радиальный градиент для карточек

UI-компонент (карточка) с radial-gradient, который следует за курсором. Радиус градиента — 200px, цвет — фирменный зелёный.

AutoGivex Platform

Инновационная платформа для автоматизации процессов. Следящий радиальный градиент создаёт эффект «прожектора», который подсвечивает элемент под курсором.

✨ Интерактивная карточка

Эффект №3 · Система частиц на Canvas

Анимированные частицы с зелёным неоновым свечением. Каждая частица — круг, нарисованный через Canvas 2D с shadowColor: #0acf83 и shadowBlur.

✦ Particle System ✦

Эффект №4 · Градиентные кнопки

Кнопки с анимированной стрелкой при :hover. Стрелка смещается translateX(-5px) → translateX(0), цвет текста меняется на зелёный.
