# Effects Site

Интерактивная демонстрация с полноэкранной системой частиц и панелью настроек.

## Возможности
- полноэкранный canvas с анимированными частицами;
- пресеты настроек: Calm, Neon, Storm, Minimal;
- управление количеством частиц, размером, скоростью, цветовой палитрой и режимом взаимодействия с курсором;
- сохранение выбранных параметров в браузере через localStorage.

## Запуск локально
Откройте файл [index.html](index.html) в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

После этого откройте http://localhost:8000/.

## Структура проекта
- [index.html](index.html) — основная разметка интерфейса;
- [css/style.css](css/style.css) — стили и оформление;
- [js/script.js](js/script.js) — логика анимации, настроек и пресетов.
