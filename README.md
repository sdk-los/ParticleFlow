# Effects Site

Статический сайт с интерактивной системой частиц и панелью настроек.

## Что включено
- полноэкранный canvas с частицами;
- панель настроек с пресетами и управлением параметрами;
- поддержка GitHub Pages без сборки.

## Локальный запуск
Откройте файл [index.html](index.html) в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

После этого откройте http://localhost:8000/.

## Публикация на GitHub Pages
1. Создайте репозиторий на GitHub.
2. Подключите его к локальному репозиторию и отправьте код.
3. В настройках репозитория откройте раздел Pages и выберите источник GitHub Actions.
4. После запуска workflow сайт будет доступен по адресу:
   https://<username>.github.io/<repo-name>/
